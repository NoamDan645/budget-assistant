# מנהל הוצאות אישי בעברית

פרויקט לימודי ב־Python, LangChain ו־LangGraph.

כולל רישום הוצאות בשיחה, סיווג לקטגוריות, תיקון קטגוריות,
תאריכי הוצאות וסיכומים כלליים וחודשיים.

ההוצאות נשמרות ב־SQLite. זיכרון השיחה נשמר בזמן שהתוכנית פתוחה.

מבנה הפרויקט:

- `backend/` — השרת, הסוכן, הכלים והגישה למסד הנתונים.
- `frontend/` — האתר בעברית.
- `data/expenses.db` — ההוצאות והתקציבים. תיקיית הנתונים אינה עולה ל־Git.
- `scripts/` — תוכניות השיחה בטרמינל.
- `.env` — מפתחות API, בתיקייה הראשית של הפרויקט.

כל הפקודות הבאות מופעלות מהתיקייה הראשית `budget-assistant`.

התקנה בתוך הסביבה הווירטואלית:

```powershell
python -m pip install -r requirements.txt
```

העתיקו את `.env.example` אל `.env` והכניסו מפתח OpenAI.

הפעלת השרת לפיתוח:

```powershell
python -m uvicorn backend.server:app --reload
```

פתחו את האתר בכתובת http://127.0.0.1:8000.
ממשק בדיקת ה־API נמצא בכתובת http://127.0.0.1:8000/docs.

הפעלת קליינט הטרמינל, בטרמינל נוסף כשהשרת פועל:

```powershell
python -m scripts.client
```

הפעלת השיחה הישירה עם הסוכן בטרמינל:

```powershell
python -m scripts.main
```

זיכרון השיחה בשרת נשמר כל עוד השרת פועל. הנתונים נשמרים ב־SQLite.
