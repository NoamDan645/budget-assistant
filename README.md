# מנהל הוצאות אישי בעברית

פרויקט לימודי ב־Python, LangChain ו־LangGraph.

כולל רישום הוצאות בשיחה, סיווג לקטגוריות, תיקון קטגוריות,
תאריכי הוצאות וסיכומים כלליים וחודשיים.

ההוצאות נשמרות ב־SQLite. זיכרון השיחה נשמר בזמן שהתוכנית פתוחה.

להפעלה: התקינו את requirements.txt בסביבה וירטואלית,
העתיקו את .env.example אל .env והכניסו מפתח OpenAI.
הריצו python main.py.
